Uniswap V3 Position Inspector

Читает позицию напрямую из блокчейна: текущие количества token0/token1, диапазон цены, статус IN/OUT OF RANGE и начисленные, но ещё не собранные комиссии.

APR/APY — оценка по текущим невостребованным комиссиям за указанный период. Если вы недавно собирали комиссии, укажите число дней после последнего collect.
Настройки поиска NFT

Поиск по кошельку сканирует события ERC-721 Transfer у Position Manager, после чего проверяет текущего владельца через ownerOf(). Некоторые бесплатные RPC ограничивают диапазон eth_getLogs; файл автоматически уменьшает шаг при ошибке.

Данные только для чтения. Комиссии вычисляются по глобальному fee growth, данным граничных ticks и последнему feeGrowthInside позиции. Значение может измениться уже в следующем блоке. Для очень старых кошельков режим поиска по адресу может быть медленным на публичном RPC.
